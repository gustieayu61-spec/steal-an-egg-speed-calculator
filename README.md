# Steal an Egg — Speed Calculator

Kalkulator berbasis browser untuk menghitung:
- Kecepatan rata-rata dari jarak dan waktu
- Estimasi waktu untuk sejumlah target
- Rata-rata telur per menit
- Perbandingan dua percobaan

## Jalankan di komputer
Buka `index.html` di browser. Tidak perlu instalasi.

## Publikasikan dengan GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html` dan `README.md` ke repository.
3. Buka **Settings → Pages**.
4. Pada bagian build/deployment, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
6. Tunggu proses selesai; GitHub akan menampilkan tautan situs.

Catatan: kalkulator ini tidak terhubung langsung ke Roblox dan tidak membaca data game otomatis. Semua perhitungan menggunakan data yang dimasukkan sendiri.
